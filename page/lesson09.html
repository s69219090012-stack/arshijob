บทที่ 9

JavaScript สมองกลผู้เนรมิตชีวิตให้เว็บไซต์

กลับหน้าหลัก
1. บทบาทของเทคโนโลยีเว็บ (Web Architecture Elements)

การพัฒนาเว็บไซต์เปรียบเสมือนการสร้างหุ่นยนต์จักรกลซึ่งประกอบด้วย 3 ส่วนสำคัญ ดังนี้:

  • โครงเหล็ก (HTML): โครงสร้างและชิ้นส่วนพื้นฐานที่ประกอบกันเป็นรูปร่าง (Structure)
  • เสื้อผ้าและสีสัน (CSS): การตกแต่งผิวภายนอกให้ดูสวยงามและเป็นระเบียบ (Presentation)
  • สมองกล (JavaScript): ระบบไฟฟ้าที่สั่งการให้ขยับ โต้ตอบ และมีความคิด (Behavior) เปลี่ยนหน้าเว็บที่ตายตัวให้กลายเป็นแอปพลิเคชันที่มีชีวิตชีวาและโต้ตอบได้แบบเรียลไทม์
2. รูปแบบการติดตั้งสคริปต์ (Integration Methods)

การเชื่อมต่อ JavaScript เข้ากับหน้าเว็บไซต์สามารถทำได้ 2 รูปแบบหลัก:

รูปแบบ การทำงาน / โครงสร้าง เปรียบเทียบ การใช้งาน
Internal Script พิมพ์โค้ดลงในแท็ก <script> โดยวางไว้ก่อนปิด </body> โน้ตคำสั่งสั้นๆ แปะไว้บนตู้เย็น เหมาะกับโค้ดขนาดเล็กที่ทำงานเฉพาะเจาะจงแค่หน้าเว็บเดียว
External Script สร้างไฟล์ .js แยก แล้วเชื่อมด้วย <script src="main.js"></script> คู่มือการทำงานแยกเป็นเล่มต่างหาก มาตรฐานมืออาชีพ โค้ดสะอาด นำไปใช้ร่วมกับหน้าเว็บอื่นๆ ได้ทันที
3. ช่องทางการสื่อสารของ JavaScript
  • alert() (กล่องป๊อปอัปแจ้งเตือน): แสดงผลเด้งขึ้นมากลางหน้าจอ บังคับให้ผู้ใช้กด OK ส่งผลหยุดการทำงานของเว็บทั้งหมดชั่วคราว เหมาะสำหรับแจ้งเตือนผู้ใช้งานทั่วไป (User)
  • console.log() (ข้อความลับหลังบ้าน): พิมพ์ข้อความลงในเครื่องมือ Console (F12) ทำงานเงียบๆ ไม่รบกวนการอ่านเว็บ เหมาะสำหรับนักพัฒนาโปรแกรม (Developer) เพื่อทดสอบโค้ด
4. การทำงานกับ DOM (Document Object Model)

DOM เปรียบเสมือน "แผงควบคุมวงจรไฟฟ้าของเว็บไซต์" โดยมีกระบวนการและหน้าที่สำคัญดังนี้:

  • การแปลงร่างของ HTML: ทันทีที่เบราว์เซอร์อ่านโค้ดเสร็จ จะสร้าง DOM ขึ้นมาครอบทับเว็บไซต์
  • สวิตช์และปุ่มกด: แท็ก HTML ทุกตัวจะถูกจำลองเป็นสวิตช์บนแผงควบคุม (เช่น <h1>, <p>, <button>, <div>)
  • หน้าที่ของ JavaScript: เอื้อมมือเข้าไปสับสวิตช์ สั่งให้หน้าเว็บขยับหรือเปลี่ยนสีได้แบบเรียลไทม์โดยไม่ต้องกดรีเฟรช
5. ขั้นตอนการควบคุม DOM ผ่านโค้ด
  • ขั้นตอนที่ 1 (ล็อกเป้าหมาย): ใช้คำสั่ง document.getElementById('id_name') เปรียบเสมือนการ "ประกาศเรียกชื่อพนักงานผ่านเสียงตามสาย" แท็ก HTML ที่มี ID ตรงกันจะถูกดึงตัวออกมารอรับคำสั่งทันที
  • ขั้นตอนที่ 2 (เปลี่ยนแปลงข้อมูล): ใช้คำสั่ง .innerHTML = 'ข้อความใหม่' เปรียบเสมือนการเดินไปที่ "กระดานไวท์บอร์ด" เพื่อลบข้อความเดิมทิ้งแล้วเขียนข้อความใหม่ทับลงไป ทำให้ข้อมูลเปลี่ยนทันทีโดยไม่ต้องโหลดหน้าเว็บใหม่
6. ตัวกระตุ้นและการดักจับพฤติกรรมผู้ใช้ (Events)

Event คือจุดเริ่มต้นของวงจรการโต้ตอบที่คอยเฝ้ารอพฤติกรรมของผู้ใช้งาน:

  • Mouse Events:
    • onclick: สัญญาณกริ่งประตู ทำงานเมื่อผู้ใช้คลิกปุ่มหรือวัตถุเพื่อปลุกชุดคำสั่ง (Function) ให้ทำงาน
    • onmouseover: ทำงานทันทีเมื่อนำเมาส์ลากไปวางพาด (ยังไม่คลิก) ใช้ดึงดูดความสนใจ
    • onmouseout: ทำงานทันทีเมื่อลากเมาส์ออกจากวัตถุ ใช้คืนค่ารูปลักษณ์เดิม
  • Keyboard Events:
    • onkeydown: ทำงานในเสี้ยววินาทีที่กดปุ่มลงไป
    • onkeyup: ทำงานทันทีเมื่อปล่อยนิ้วขึ้น เหมาะสำหรับการตรวจสอบข้อมูลแบบสดๆ (Real-time Validation) ขณะพิมพ์ เช่น การตรวจสอบรหัสผ่าน
7. เหตุผลที่ต้องใช้ JavaScript (Validation)

เปรียบเทียบข้อจำกัดของระบบเดิมและการนำ JavaScript มาประยุกต์ใช้ในการตรวจสอบข้อมูล:

  • ขีดจำกัดของ HTML5: ตรวจสอบได้แค่กฎพื้นฐาน (เช่น ห้ามเว้นว่าง, กำหนดค่าต่ำสุด-สูงสุด) แต่ไม่สามารถเช็กความซับซ้อน เช่น ตรวจสอบว่ารหัสผ่าน 2 ช่องตรงกันหรือไม่
  • โซลูชันจาก JavaScript (Custom Validation): ทำหน้าที่เหมือน "พนักงานรักษาความปลอดภัยสุดสมาร์ท" ที่ดึงข้อความขณะพิมพ์ (ใช้ .value) มาตรวจสอบด้วยเงื่อนไขอิสระ สร้างประสบการณ์ใช้งาน (UX) ที่ลื่นไหลและป้องกันข้อผิดพลาดได้ดีกว่า
