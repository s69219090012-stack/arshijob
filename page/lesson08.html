บทที่ 8

การออกแบบและสร้างฟอร์ม (Forms)

กลับหน้าหลัก
1. องค์ประกอบและโครงสร้างของฟอร์ม (Form Structure)

ฟอร์ม (Form) ทำหน้าที่เป็นพื้นที่รับฟังข้อมูลจากผู้ใช้งานเพื่อสร้างการสื่อสารแบบสองทาง (Two-way Communication) โดยประกอบด้วยส่วนสำคัญดังนี้:

  • โครงสร้างแท็ก <form>: เปรียบเสมือน "ซองจดหมาย" หรือ "กล่องพัสดุ" ช่องกรอกข้อมูลและปุ่มกดทั้งหมดต้องบรรจุอยู่ภายในคู่แท็กนี้ หากหลุดออกไปภายนอก ข้อมูลจะไม่ถูกส่งไปยังเซิร์ฟเวอร์
  • action: เปรียบเสมือน "ที่อยู่ปลายทางบนหน้าซองจดหมาย" ระบุ URL หรือเส้นทางของไฟล์ฝั่ง Server (เช่น PHP/Backend) ที่จะรับข้อมูลไปประมวลผล
  • label คู่กับ input: การเชื่อมโยง <label for="id_name"> กับ <input id="id_name"> ช่วยให้เมื่อคลิกที่ตัวอักษร ข้อความเคอร์เซอร์จะกระโดดเข้าช่องกรอกทันที เพิ่มประสบการณ์ผู้ใช้งาน (UX) บนหน้าจอมือถือ
2. เปรียบเทียบวิธีการส่งข้อมูล (Method: GET vs POST)

การเลือกใช้ Method ระบุวิธีการจัดส่งข้อมูล มีมาตรฐาน 2 รูปแบบหลัก ดังนี้:

คุณสมบัติ GET POST
ลักษณะการส่ง เปรียบเสมือน "ไปรษณียบัตร" แปะข้อมูลต่อท้าย URL เปรียบเสมือน "ซองจดหมายปิดผนึก" ซ่อนข้อมูลไว้ในเบื้องหลัง
ความปลอดภัย เห็นข้อมูลชัดเจนบน URL ไม่เหมาะกับข้อมูลลับ มีความปลอดภัยสูง ซ่อนข้อมูลส่วนตัวหรือรหัสผ่านได้
ปริมาณข้อมูล จำกัดปริมาณข้อความ ไม่จำกัดปริมาณข้อมูล สามารถส่งไฟล์ขนาดใหญ่ได้
ความจำเป็น / การนำไปใช้ เหมาะสำหรับคำค้นหา (Search Query) ที่แชร์ลิงก์ได้ เหมาะสำหรับระบบเข้าสู่ระบบ สมัครสมาชิก หรือส่งข้อมูลลับ
3. ประเภทของช่องรับข้อมูล (Input Types)

แท็ก <input> เปรียบเสมือน "กิ้งก่าเปลี่ยนสี" ที่เปลี่ยนรูปแบบตามค่าของแอตทริบิวต์ type โดยแบ่งเป็นกลุ่มหลักดังนี้:

  • กลุ่มช่องกรอกข้อความ (Text-based Inputs):
    • type="text": ช่องกรอกข้อความบรรทัดเดียวมาตรฐาน สำหรับข้อมูลทั่วไป เช่น ชื่อ-นามสกุล
    • type="password": พรางตัวอักษรเป็นจุดกลมดำเพื่อป้องกันการแอบมองรหัสผ่าน
    • type="email": ตรวจสอบโครงสร้างอีเมล (ต้องมี @ และโดเมน) และปรับคีย์บอร์ดมือถือให้อัตโนมัติ
  • กลุ่มช่องสำหรับเลือก (Selection-based Inputs):
    • type="radio": ปุ่มวงกลม บังคับเลือกได้เพียงข้อเดียวเท่านั้น (เช่น เพศ, ไซส์เสื้อ)
    • type="checkbox": กล่องสี่เหลี่ยม เลือกได้หลายข้อพร้อมกัน หรือไม่เลือกเลยก็ได้ (เช่น งานอดิเรก)
    • <select> และ <option>: เมนูดรอปดาวน์ (Dropdown) ช่วยประหยัดพื้นที่บนหน้าจอเมื่อมีตัวเลือกจำนวนมาก (เช่น เลือกจังหวัด)
4. การตรวจสอบความถูกต้องของข้อมูล (Form Validation)

ระบบ Built-in Validation ของ HTML5 เปรียบเสมือน "พนักงานตรวจเอกสารอัตโนมัติ" ที่ช่วยป้องกันความเสียหายจากข้อมูลที่ผิดพลาดก่อนส่งไปยังหลังบ้าน:

  • required: บังคับว่าต้องกรอกข้อมูล หากปล่อยว่าง เบราว์เซอร์จะระงับการส่งและขึ้นป๊อปอัปเตือนทันที
  • min และ max: กำหนดขอบเขตค่าต่ำสุดและสูงสุด ใช้กับตัวเลข (type="number") หรือวันที่ (type="date") เช่น กำหนดอายุช่วง 18 - 60 ปี
